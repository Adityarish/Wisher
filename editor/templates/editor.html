    3 · Prefer the command line?

    Drop files in user_data/inbox/ and run python user_data/helper.py --project default. It uses exactly the same rules. Add --dry-run to preview.

    Good to know

    • Photos up to ~15 MB and videos up to ~80 MB load comfortably.
    • Folder uploads from the browser are limited to 120 MB at a time. For larger sets use the command line.
    • Captions come from file names. Add Hindi or emoji captions in the Media step.
    • reasons.txt lets you write your own “100 reasons”. Missing ones are filled with built-in lines.
